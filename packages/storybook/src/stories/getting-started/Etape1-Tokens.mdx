# Étape 1 — Intégrer tes tokens Figma

Les tokens sont les valeurs fondamentales de ton Design System :
couleurs, typographie, espacements, rayons de bordure.

Cette étape transforme tes variables Figma en variables CSS
utilisables dans tous tes composants.

## Comment ça marche

```
Figma Variables  →  packages/tokens/tokens.json  →  Style Dictionary  →  variables CSS
(source de vérité)   (reporté à la main)            (build)               (build/css/)
```

Figma reste la source de vérité. Il n'y a pas d'export automatique :
chaque changement fait dans Figma est **reporté à la main** dans
`packages/tokens/tokens.json`, puis le build génère les fichiers CSS.

## 1. Modifier la variable dans Figma

Dans le panneau **Variables** de Figma, crée, renomme ou modifie la variable.
Respecte la nomenclature existante (échelle numérique : `x4`, `x6`, `x3-5`…).

## 2. Reporter le changement dans tokens.json

Ouvre `packages/tokens/tokens.json` et applique exactement le même changement,
au même emplacement. Chaque token a une valeur (`$value`) et un type (`$type`) :

```json
{
  "primitive": {
    "typography": {
      "line-height": {
        "x6": {
          "$value": 24,
          "$type": "number"
        }
      }
    }
  }
}
```

Le fichier contient deux groupes racine :

- **`primitive`** — tokens bruts (couleurs, spacing, sizing, border-radius,
  elevation, typographie) → `build/css/primitive.css`
- **`semantic`** — tokens sémantiques (boutons, textes, notifications…)
  → `build/css/semantic.css`

Le nom de la variable CSS reprend le chemin du token, sans le groupe racine :

```
primitive › typography › line-height › x6   →   --typography-line-height-x6
```

Ce lien entre groupe racine et fichier CSS est défini dans
`packages/tokens/mapping.config.js` (clé `figmaCollection`). Tu n'as à le
modifier que si tu ajoutes un nouveau groupe racine.

## 3. Lancer le build des tokens

```bash
pnpm --filter @brique-rouge/tokens build
```

Le build convertit automatiquement les valeurs :

- **Couleur** → hex, tel que saisi (`#3453dc`, ou `#0000000f` avec opacité)
- **Nombre** → en `px` (`24` → `24px`)
- **Nombre sous `opacity`, `font-weight` ou un ratio de `line-height`**
  (`tight`, `normal`…) → sans unité (`500`, `1.5`)
- **`font-family`** → nom entre guillemets + police de secours
  (`"GT Ultra", serif`)

Le build régénère aussi la documentation `specs/foundations/` et `specs/tokens/`.
Ajoute ces fichiers à ton commit : la CI vérifie qu'ils sont à jour.

## 4. Vérifier dans Storybook

Navigue dans **Fondations** dans le menu à gauche.

✅ Tu vois tes couleurs, ta typographie et tes espacements ?
Les tokens sont correctement intégrés.
Continue avec **Étape 2 — Premier composant**.
